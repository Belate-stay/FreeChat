# Beta 1.2.2.3 implementation plan

**Goal:** Match character-picker selection to Favorites, create named groups through a settings draft, clarify image-generation labels, place the contribution invitation at the page bottom, and replace the retired scene recommendation with two real-rendered, measurable recommendations.

**Architecture:** Reuse the existing character library rows, non-linear Compose motion, SheetPanel and GroupSettingsScreen. A group is a local draft until both members and its user-entered title are valid and Start is pressed. Group defaults remain separate from persona snapshots; private conversations/source cards are unaffected. Recommendation rendering and server/admin metrics are independent delegated tasks; Gradle/device work stays serial under the root agent.

**Approved behavior:** Selecting roles opens group settings with an initial naming prompt. Canceling that prompt leaves a blank-name draft with Start disabled. Returning to the picker retains selected roles/settings. Group settings can adjust name, announcement, models and reply preferences before creation. Start persists exactly one conversation using the user's trimmed name, then opens Chat. Existing-group member additions retain their prior flow. Story uses “生图模型” for its generation-model row and chooser. The contribution invitation sits at the bottom with comfortable, readable copy; existing upload confirmation/data scope is unchanged.

**Recommendation navigation:** Both pages can always swipe horizontally in either direction. Buttons unlock after 4 seconds of foreground settled-page dwell, independently of full playback. Each page retains its own playback/dwell/reading state. Page impressions and explicit Next/Done/swipe actions are counted separately through the existing event endpoint; the final page alone marks the version read. Server/admin modifications stay local without deployment.
