# Beta 1.2.0.3 实施计划

> 执行方式：同一会话内按 subagent-driven-development 分配互不重叠的设置、创建表单任务，主线程负责导航、整合与串行验证。禁止并行 Gradle。未经要求不提交、推送或部署。

设计依据：[已确认设计](../specs/2026-10-16-tablet-display-navigation-design.md)。

- [x] 1. 添加纯布局／导航策略及回归测试，先验证失败，再实现；覆盖默认显示方式、来源侧、卡片边界和连续画布位置。
- [x] 2. 持久化显示偏好；平板设置顶部增加优化栏目与条件位置项；手机不出现该栏目。验证默认模型页不因目录插入而改变。
- [x] 3. 重用角色表单实现三栏目创建流程；未选模式禁止后两项，草稿与导入不丢失；验证原有保存、忙碌与学习规则。
- [x] 4. 整合连续 Chat 画布、大页面双侧转场、分隔线联动；保持单一真实 Chat 和各页面状态，保留设置内部动画。
- [x] 5. 实现不调暗背景的悬浮手机卡片，隔离背景所有交互、支持三种侧偏好和轻微回弹；新对话仍嵌入。
- [x] 6. 运行单元测试、核心测试、debug/release 编译；审查范围、方向与旧功能契约。
- [x] 7. 模拟器截图／录屏验证横竖屏、嵌入／悬浮、创建、返回、忙碌与学习隔离；修复发现的问题，不以模拟器代替真机帧率结论。
- [x] 8. 更新 Beta 1.2.0.3 版本与更新日志，输出签名安装包和可追溯验证记录。
